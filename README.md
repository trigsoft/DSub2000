# This is Clone of DSub2000

Among all the Airsonic clients, DSub2000 is the only one that I like. But there are still some small things I want to improve. 

## Changes

* Add preference to change the auto hide delay for media control
* The settings fragment will get back to main setting list rather to main activity
* Keep list names on one line with end ellipses, while preserving multiline player and detail titles
* Show multiple music libraries as a folder selection list, including an all-folders option
* Add an Amperfy-inspired album detail header with centered artwork, album information, and Play/Shuffle buttons
* Use a centered album toolbar title without a dropdown, duplicate playback buttons, or shadow
* Recognize album details in tag browsing and folder/offline browsing when consistent track metadata identifies an album, even if its folder name differs
* Add separate song and album settings for showing favorites, sharing, and ratings under Settings > Appearance; existing visibility preferences are preserved
* Add an Amperfy-inspired player backdrop using two dominant artwork colors, a vertical gradient, and blurred artwork
* Display rounded player artwork at up to 90% of the available width, shrinking when vertical space is limited
* Center landscape player artwork at 90% of the available square in the artwork pane, keeping playback controls alongside it
* Split landscape playback into equal-width artwork and control panes; center song information and playback controls horizontally and vertically within the right pane, retaining expandable queue space on large screens
* Vertically center the portrait player's artwork, song information, and controls as a group while preserving queue behavior
* Reduce repeat and queue icon sizes without changing their button sizes or touch targets
* Remove top toolbar shadows throughout the app, including player and settings screens
* Add themed separators to list rows, including playback queues and settings, without adding lines to artwork grids

The app uses the application ID `com.flowtech.dsub2000more`, so it installs separately from the original DSub2000 and does not share its settings or data.
